## 🤔 Зачем

Современный «умный» телевизор — это рекламный щит, за который вы заплатили:

- на главном экране — ряды «рекомендаций», промо онлайн-кинотеатров и баннеры;
- в фоне — сбор статистики и системы распознавания того, что вы смотрите (ACR), чтобы точнее показывать рекламу;
- десятки предустановленных приложений, которые съедают и без того скромные 1–2 ГБ памяти;
- YouTube в России тормозит, а встроенное приложение показывает рекламу.

ЧистыйТВ делает то же, что делают руками на 4PDA, только по готовым проверенным спискам и с откатом.

## 🚀 Как пользоваться

1. **Включите отладку на телевизоре** — для каждой платформы по-своему, пошагово: [docs/ADB.md](docs/ADB.md).
   Коротко для Android TV / Google TV: Настройки → Система → Об устройстве → 7 раз «Сборка» →
   «Для разработчиков» → «Отладка по USB» (и «по сети», если есть).
2. **Запустите на компьютере** в той же Wi-Fi сети:
   ```powershell
   irm https://raw.githubusercontent.com/by-sonic/chistytv/main/chistytv.ps1 | iex
   ```
3. **Подтвердите на телевизоре** окно «Разрешить отладку?» и выберите в меню, что делать:
   ```
   1. Убрать рекламу и мусор
   2. YouTube без тормозов: SmartTube + VPN
   3. Новый главный экран без рекламных рядов
   4. Блокировка рекламы через DNS
   5. Вернуть как было
   ```
4. **В конце выключите отладку** на телевизоре — ЧистыйТВ напомнит.

### Без меню, для опытных

```powershell
git clone https://github.com/by-sonic/chistytv; cd chistytv
.\chistytv.ps1 -TvIp 192.168.1.50 -Action clean      # clean | youtube | launcher | dns | restore | info
.\chistytv.ps1 -TvIp 192.168.1.50 -Action youtube -Subscription "https://ваша-ссылка-подписки"
```

Флаг `-Yes` отвечает «по умолчанию» на все вопросы: отключается только рекомендуемое, ваши приложения не трогаются.

## 🛡 Безопасность

- **Только отключение.** `pm disable-user`, никаких удалений. Всё, что отключил ЧистыйТВ, записывается в
  `Документы\ChistyTV\<модель>\disabled-by-chistytv.txt`, и пункт «Вернуть как было» включает это обратно.
- **Бэкап до изменений**: список приложений, `getprop` и все системные настройки.
- **Защита от ошибок в базе**: пакеты входов, эфира, пульта, клавиатуры, установщика, Wi-Fi и заводских
  меню скрипт не тронет, даже если они окажутся в списке.
- **Штатный лаунчер** отключается только если вы явно попросили, только вместе с парными пакетами и
  никогда — если пакет владеет сохранённой сетью Wi-Fi. Не помогло — скрипт сам всё вернёт.
- **Приложения — только с официальных GitHub** разработчиков: SmartTube, Happ, LTvLauncher. ADB — с
  `dl.google.com`.
- **Ничего не отправляет автору.** Ссылка подписки уходит только на ваш телевизор. Исключение — запасной
  импорт через официальный сервис Happ, о нём скрипт спросит отдельно.

## ❓ FAQ

**Это законно? Гарантия не слетит?**
Отладка — штатная функция Android, root не нужен, система не модифицируется. Всё отключённое включается обратно.

**Компьютера нет, только телефон.**
Есть [приложение для Android](android/README.md) — то же самое по Wi-Fi с телефона, включая подключение
по коду для Android 11+. На iPhone так не получится: iOS не даёт приложениям работать с ADB.

**Мой телевизор — Samsung или LG.**
Tizen и webOS — не Android, ЧистыйТВ с ними не работает. Для YouTube проще всего приставка на Android TV.

**После обновления прошивки реклама вернулась.**
Так бывает, особенно на Яндекс ТВ. Запустите ЧистыйТВ ещё раз — он отключит вернувшееся. Можно отключить
и обновления (пункт спросят отдельно), но тогда не придут и исправления.

**Что-то перестало работать.**
Запустите ЧистыйТВ → «Вернуть как было» → перезагрузите ТВ. И напишите в issue модель и что сломалось —
поправим базу для всех.

**Нужен ли VPN?**
Для чистки — нет. Для YouTube в России без тормозов — да: SmartTube убирает рекламу, но не замедление.
Подойдёт любой VPN с подпиской для Happ. Если своего нет — [RoseVPN](https://t.me/rosevpnru_bot) с
бесплатным пробным периодом.
